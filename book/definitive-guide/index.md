# Python Polars: The Definitive Guide

Chapters that follow *Python Polars: The Definitive Guide* by
Jeroen Janssens and Thijs Nieuwdorp (O'Reilly, 2025), using the code of its
[companion repository](https://github.com/jeroenjanssens/python-polars-the-definitive-guide),
which is MIT licensed.

The licence covers the book's code, not its text. So these chapters keep the book's code,
section headings and data, and put the Nanuq book's own short text between them: they are
a companion to the book, not a copy of it. Read the book for the explanations. As in the
rest of the Nanuq book, every example runs in Nim and in Python, and the remarks on how
Nanuq differs are in boxes marked “Nanuq”.
