# Modern Polars

Chapters of [*Modern Polars*](https://kevinheavey.github.io/modern-polars/) by Kevin Heavey,
a side-by-side comparison of Polars and pandas in the spirit of Tom Augspurger's
*Modern Pandas*. The book is licensed under
[CC BY 4.0](https://github.com/kevinheavey/modern-polars/blob/master/LICENSE.md), so its text is
kept, adapted where it compares Polars with pandas.

The ports keep the Polars side of each comparison: the original Python Polars code is in the
Python tab, next to its Nim port, and the pandas code is left out. As in the rest of the
Nanuq book, both tabs run, and the remarks on how Nanuq differs are in boxes marked “Nanuq”.
