# Polars Cookbook

Recipes that follow the [*Polars Cookbook*](https://www.packtpub.com/en-us/product/polars-cookbook-9781805121152)
by Yuki Kakegawa (Packt, 2024), using the code of its
[companion repository](https://github.com/PacktPublishing/Polars-Cookbook), which is MIT
licensed.

The licence covers the book's code, not its text. So these chapters keep the recipes'
code, headings and data, and put the Nanuq book's own short text between them: they are a
companion to the book, not a copy of it. Read the book for the explanations. As in the
rest of the Nanuq book, every example runs in Nim and in Python, and the remarks on how
Nanuq differs are in boxes marked “Nanuq”.
