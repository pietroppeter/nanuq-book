# Real Python tutorials

Ports of the code of [Real Python](https://realpython.com/)'s Polars tutorials, from the
notebooks and data in its [materials repository](https://github.com/realpython/materials),
which is MIT licensed.

The licence covers the code, not the tutorials' text. So these chapters keep the
tutorials' code and data, and put the Nanuq book's own short text between them: read the
tutorials for the explanations. As in the rest of the book, every example runs in Nim and in
Python, and the remarks on how Nanuq differs are in boxes marked “Nanuq”.
